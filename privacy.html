MRE HOA Tools: Privacy Policy

Effective October 30, 2026.

Who uses it

MRE HOA Tools is used only by officers of the Miner's Ravine Estates Homeowners Association, on the association's own Google account. It has no other users.

What it accesses

With the account owner's permission, the tool reads and edits files in Google Drive, Docs and Sheets, and reads Gmail, Calendar and Slides. It uses this access only to manage the association's records and correspondence.

Where data goes

Data is processed on the officer's own computer. Sign-in credentials are stored encrypted on that computer. The tool does not sell, share or transfer Google user data to anyone, and does not use it for advertising.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account owner can remove the tool's access at any time at myaccount.google.com/permissions.
